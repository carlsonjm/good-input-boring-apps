# Known limits

## Not yet

- Page corners are the engine's square ones; the mock-up's rounded paper waits
  on knowing where each page lies.
- The Sheets grid has no column letters or row numbers yet, and no fill handle
  drag. Typing goes into the chosen cell; there is no in-place cell editor of
  our own.
- Slides edits text on a slide but cannot add or move pictures and shapes yet.
- Link in the selection bar uses the engine's link command; it may not take an
  address on every engine version.
- Find, print, rename, word count and a document's comments list are not in
  More yet.
- A file with a password does not open.
- Icons follow the colour scheme in two inks; the desk follows the scheme, the
  page stays the document's own colour.
- The engine runs inside the program; a crash in it takes the window with it.
- Not yet a Flatpak.

## Not planned

- Tracked changes, mail merge, macros and forms.
- Real-time editing by several people.
